# EGAT OT Calculator — ระบบคำนวณล่วงเวลา (OT) สำหรับพนักงาน กฟผ.

เว็บแอปพรีเวอร์ซิฟ (PWA) สำหรับบันทึกและคำนวณชั่วโมงทำล่วงเวลา (OT) ของพนักงาน/พขร.
ใช้งานผ่านเบราว์เซอร์ได้ทั้งบนคอมพิวเตอร์และมือถือ และติดตั้งลงเครื่องเป็นแอปได้
ไม่ต้องติดตั้งโปรแกรมเพิ่ม และรองรับการทำงานแบบออฟไลน์

เวอร์ชันปัจจุบัน: **v7.8.0**

## คุณสมบัติของแอป

### 1. คำนวณเวลา OT
- บันทึกเวลาเริ่มต้น–สิ้นสุด และช่วงเวลาพัก (เช่น เที่ยงอาหาร) เพื่อหักเวลาพักออกโดยอัตโนมัติ
- คำนวณค่าแยกตามอัตรา **OT ×1.5 / ×1 / ×3** ตามประเภทวัน (วันธรรมดา / วันหยุด)
- แสดงยอดรวมที่จะขอเบิก และสถานะการขึ้นใบรับรองเอกสาร
- รองรับการแบ่งรายการตามรายชื่อพนักงาน (ลากกล่องรายชื่อมาวางได้ — Drag & Drop)

### 2. สรุปรายเดือน
- **โหมดปกติ** — สรุปแยกรายวัน แสดงชั่วโมง OT แต่ละอัตราและยอดรวมขอเบิก
- **โหมด พขร. (ยอดรวม)** — สรุปยอดรวมสะสมของพนักงานแต่ละราย
- ตัวกรองตามเดือนและชื่อพนักงาน พร้อมปุ่ม "สรุปด่วน" (Quick Summary) แสดงภาพรวมทันที

### 3. รายชื่อ พขร.
- เพิ่ม / แก้ไข / ลบรายชื่อพนักงาน
- เก็บประวัติการทำ OT และสถานะการยืนยันเอกสารของแต่ละราย
- ค้นหาและกรองรายชื่อได้

### 4. เครื่องคิดเลข
- คำนวณ OT แบบรวดเร็วโดยไม่ต้องบันทึกลงประวัติ (เหมาะสำหรับการเช็กค่าเบื้องต้น)

### 5. สำรองและนำเข้าข้อมูล
- ดาวน์โหลดข้อมูลทั้งหมดเป็นไฟล์ `.json`
- นำเข้าข้อมูลกลับเข้าระบบได้ รองรับทั้งข้อมูลทั้งหมด ประวัติทำ OT และสถานะการยืนยัน

### 6. ซิงค์ข้อมูลกับ Google Apps Script
- ซิงค์ข้อมูลอัตโนมัติขึ้น Google Sheets ผ่าน Google Apps Script (Web App)
- มีคิวรอซิงค์ ถ้าอินเทอร์เน็ตขัดข้องข้อมูลจะถูกส่งใหม่เมื่อกลับมาออนไลน์
- บีบอัดข้อมูลอัตโนมัติก่อนบันทึก เพื่อป้องกันไฟล์ใหญ่เกินโควตาของ Google

### 7. อื่น ๆ
- ติดตั้งเป็น PWA ใช้งานได้แบบออฟไลน์
- รองรับมือถือ (Responsive) และแถบเมนูด้านข้างแบบพับได้
- บันทึกร่างฟอร์ม (Draft) อัตโนมัติ หากปิดหน้าเว็บกลางทาง
- แปลงวันที่เป็น พ.ศ. พร้อมเลือกเดือน/ปีแบบกำหนดเอง

## วิธีติดตั้ง PWA

> **ข้อสำคัญ:** Service Worker จะทำงานเฉพาะเมื่อเปิดผ่าน `http://localhost` หรือ `https://`
> หากเปิดไฟล์โดยตรง (`file:///`) เมนูติดตั้ง PWA จะไม่ปรากฏ

### ขั้นตอนที่ 1 — เปิดแอปผ่าน Local Server

**วิธี A: ใช้ Python (แนะนำ)**

```bash
cd /path/to/EgatOtCalculator
python -m http.server 8000
```

**วิธี B: ใช้ Node.js**

```bash
npx serve .
# หรือ
npx http-server -p 8000
```

**วิธี C: ใช้ Live Server ใน VS Code**

ติดตั้งส่วนขยาย **Live Server** แล้วคลิกขวาที่ `index.html` → **Open with Live Server**

### ขั้นตอนที่ 2 — ติดตั้งแอป

1. เปิดเบราว์เซอร์ไปที่ `http://localhost:8000`
2. เลือกเมนูติดตั้งแอป:
   - **Chrome / Edge (คอมพิวเตอร์):** ไอคอนติดตั้ง (⊕) บนแถบที่อยู่ → **Install**
   - **Android (Chrome):** เมนู ⋮ → **Add to Home screen**
   - **iOS (Safari):** แชร์ → **Add to Home Screen** (iOS รองรับเฉพาะ Safari)
3. เมื่อติดตั้งสำเร็จ แอปจะเปิดในโหมด `standalone` ไม่มีแถบเบราว์เซอร์

### ขั้นตอนที่ 3 — อัปเดตแอปหลังแก้ไขโค้ด

1. เปิด `chrome://serviceworker-internals` แล้วกด **Unregister**
2. หรือเปลี่ยนชื่อแคชใน `sw.js` เช่น `const CACHE_NAME = "ot-calculator-v7.4.5";`
   (ชื่อแคชต้องเปลี่ยนทุกครั้งที่อัปเดต แคชเก่าจะถูกลบอัตโนมัติ)

### การติดตั้งบนเซิร์ฟเวอร์จริง (Production)

อัปโหลดไฟล์ทั้งหมดขึ้น GitHub Pages / Netlify / เว็บเซิร์ฟเวอร์ของ กฟผ.
โดยต้องเป็นโดเมน **HTTPS** เท่านั้น PWA จึงจะทำงานได้เต็มรูปแบบ

## โครงสร้างไฟล์

```
EgatOtCalculator/
├── index.html              # โครงสร้างหน้าเว็บ (HTML) ทั้งหมด
├── manifest.json           # ข้อมูล PWA (ชื่อแอป, ไอคอน, สีธีม)
├── sw.js                   # Service Worker (แคชไฟล์แบบออฟไลน์)
├── README.md               # เอกสารนี้
│
├── assets/
│   └── icons/
│       ├── icon-192.png    # ไอคอนสำหรับ PWA / favicon
│       └── icon-512.png    # ไอคอนขนาดใหญ่ (รวม maskable)
│
├── css/
│   └── styles.css          # สไตล์ทั้งหมดของแอป
│
├── js/
│   └── app.js              # ตรรกะทั้งหมดของแอป
```

> ไฟล์สำรองข้อมูล (`egat_ot_backup_*.json`) **ไม่ถูกเก็บใน Git**
> เพราะมีข้อมูลส่วนบุคคล (ชื่อ-นามสกุล เบอร์โทรศัพท์) ดูหมวด [.gitignore](#ไฟล์ที่ไม่ถูกเก็บใน-git)

### แผนผังการอ้างอิงพาธ

| ไฟล์ | พาธที่อ้างอิง |
| --- | --- |
| `index.html` | `./css/styles.css`, `./js/app.js`, `./manifest.json`, `./assets/icons/icon-192.png` |
| `manifest.json` | `./assets/icons/icon-192.png`, `./assets/icons/icon-512.png` |
| `sw.js` | `./css/styles.css`, `./js/app.js`, `./assets/icons/*.png` |

> ทุกพาธใช้รูปแบบ `./` (relative) จึงทำงานได้ทั้งบน localhost และโดเมนจริง

### ไฟล์ที่ไม่ถูกเก็บใน Git

ไฟล์สำรองข้อมูลที่ดาวน์โหลดจากแอป (`egat_ot_backup_*.json`) จะถูกบันทึกอยู่ในโฟลเดอร์โปรเจกต์
แต่ **ไม่ถูก commit ขึ้น Git** เนื่องจากมีข้อมูลส่วนบุคคลของพนักงาน (ชื่อ-นามสกุล เบอร์โทรศัพท์)
ดังนั้นอย่าเผยแพร่ไฟล์เหล่านี้ต่อสาธารณะ

หากเคย commit ไฟล์เหล่านี้ไปแล้ว ต้องล้างออกจากประวัติ Git ด้วย
(เช่น `git filter-repo --path egat_ot_backup_drivers_2026-03-16.json --invert-paths`)
เนื่องจากประวัติ Git สาธารณะจะลบข้อมูลที่เคย push ออกไปไม่ได้

## รายละเอียดการทำงาน

### เทคโนโลยีที่ใช้

| รายการ | รายละเอียด |
| --- | --- |
| Frontend | HTML5 + CSS3 + JavaScript (vanilla ไม่พึ่งเฟรมเวิร์ก) |
| ฟอนต์ | Sarabun (Google Fonts) |
| UI | Sidebar + Card-based design, รองรับ Responsive |
| การเก็บข้อมูล | `localStorage` เป็นหลัก |
| การซิงค์ | Google Apps Script Web App → Google Sheets |
| PWA | Web App Manifest + Service Worker (Cache API) |

### การจัดเก็บข้อมูลในเบราว์เซอร์

| Key | ข้อมูล |
| --- | --- |
| `egat_drivers` | รายชื่อพนักงาน พขร. |
| `egat_ot_history` | ประวัติการทำ OT ทั้งหมด |
| `egat_ot_verified_status` | สถานะการยืนยันเอกสาร |
| `egat_ot_form_draft` | ร่างฟอร์มที่กำลังกรอก |

### กลไกการซิงค์ข้อมูล

1. ผู้ใช้บันทึกข้อมูล → เขียนลง `localStorage` ทันที (ทำงานได้แม้ไม่มีเน็ต)
2. ระบบพยายามส่งขึ้น Google Apps Script
3. หากส่งไม่สำเร็จ (ไม่มีเน็ต / โควตาเต็ม) ข้อมูลจะถูกเก็บในคิว
4. เมื่อกลับมาออนไลน์ ระบบส่งข้อมูลในคิวที่ค้างอยู่ให้อัตโนมัติ
5. ก่อนส่ง ระบบจะลบฟิลด์ที่ไม่จำเป็น (`html`, `maxOTMinutes`, `dispTotalMinutes`)
   ออกเพื่อลดขนาดไฟล์

### โครงสร้าง Service Worker

- **install** — แคชไฟล์หลักทั้งหมด (HTML, CSS, JS, ไอคอน, manifest)
- **activate** — ลบแคชเวอร์ชันเก่า และควบคุมหน้าเว็บทันที
- **fetch** — กลยุทธ์ *stale-while-revalidate*
  (ตอบจากแคชทันที แล้วค่อยดึงเวอร์ชันใหม่ไปอัปเดตแคชเบื้องหลัง)
- **Offline fallback** — หากออฟไลน์และไฟล์ไม่ถูกแคช ระบบจะแสดง `index.html`

## การสำรองและกู้คืนข้อมูล

### สำรองข้อมูล

1. กดเมนู **💾 สำรอง/นำเข้าข้อมูล** ที่แถบด้านข้าง
2. เลือกขอบเขตข้อมูล (ทั้งหมด / ประวัติทำ OT / สถานะ)
3. เลือกเดือน (ถ้าต้องการ)
4. กด **ดาวน์โหลดไฟล์ .json**

ไฟล์จะมีชื่อในรูปแบบ `egat_ot_backup_<ขอบเขต>_<วันที่>.json`

### กู้คืนข้อมูล

1. กดเมนู **💾 สำรอง/นำเข้าข้อมูล**
2. กด **นำเข้าข้อมูล (.json)** แล้วเลือกไฟล์ที่ต้องการ
3. ยืนยันการนำเข้า — ระบบจะเขียนข้อมูลกลับเข้า `localStorage`

> ควรสำรองข้อมูลอย่างสม่ำเสมอ เพราะข้อมูลทั้งหมดถูกเก็บไว้ในเบราว์เซอร์ของอุปกรณ์นั้น
> หากล้างข้อมูลเว็บไซต์ (Clear site data) ข้อมูลจะหายถาวร

## การแก้ปัญหา

### เมนูติดตั้ง PWA ไม่ปรากฏ
- ตรวจสอบว่าเปิดผ่าน `http://localhost` หรือ `https://` — **ไม่ใช่** `file:///`
- ตรวจสอบว่า `manifest.json` และ `sw.js` อยู่ที่ root ของโปรเจกต์และเข้าถึงได้
- เปิด DevTools → **Application** → ตรวจสอบว่า Service Worker สถานะเป็น *Activated*
- ล้างแคช: DevTools → Application → **Clear site data**

### แอปยังแสดงเวอร์ชันเก่า
- เปลี่ยน `CACHE_NAME` ใน `sw.js` เป็นเวอร์ชันใหม่
- หรือ unregister Service Worker ผ่าน `chrome://serviceworker-internals` แล้วรีเฟรช

### ข้อมูลไม่ซิงค์ขึ้น Google Sheets
- ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต
- ตรวจสอบว่า URL ใน `WEB_APP_URL` (บรรทัดที่ 4 ของ `js/app.js`) ยังใช้งานได้
  และ Apps Script ได้เปิดสิทธิ์เป็น *"Anyone"* หรือ *"Anyone with Google account"*
- ข้อมูลที่ค้างในคิวจะถูกส่งใหม่โดยอัตโนมัติเมื่อกลับมาออนไลน์

### บันทึกข้อมูลไม่ได้ (Local storage quota exceeded)
- ประวัติทำ OT สะสมมากจนเกินโควตาของเบราว์เซอร์ (~5 MB)
- ให้สำรองข้อมูลแล้วลบรายการเก่าที่ไม่จำเป็นออก
- หรือเปิดใช้งานโหมดซิงค์กับ Google Apps Script เพื่อเก็บข้อมูลไว้บน Cloud

### ตัวอักษรไทยแสดงผลไม่ถูกต้อง
- ตรวจสอบว่าไฟล์ทั้งหมดถูกบันทึกเป็น **UTF-8**
- ตรวจสอบ `<meta charset="UTF-8">` ใน `index.html` (บรรทัดที่ 4)
